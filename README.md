# Afrology 🐘
Learn African languages and culture with Tembo.

**Try it:** open the GitHub Pages link in **Google Chrome** (voice features need Chrome + microphone).

## Features
- 12 African languages with lessons: matching, sentence building, speaking, typing, proverbs
- AI chat tutor (Swahili + Amharic demo)
- AI voice chat with pronunciation scoring (Swahili + Amharic demo)
- Garden that grows when you learn and wilts when you skip
- Tembo the elephant + a cultural character for every language

## Tech
HTML/CSS/JavaScript app (wrapped for iOS with Capacitor). Python/FastAPI backend on Modal GPUs with a fine-tuned Llama 3.2 3B tutor, SpeechBrain Amharic speech-to-text, and OmniVoice Amharic text-to-speech (being connected).
